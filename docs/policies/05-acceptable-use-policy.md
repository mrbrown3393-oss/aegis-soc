# Acceptable Use Policy

| | |
|---|---|
| Document ID | AEG-AU-001 |
| Version | 1.0 |
| Parent Policy | AEG-ISP-000 |

1. Platform access is granted for authorized security operations and administration only.
2. Credentials and sessions are personal and non-transferable; sharing is prohibited. Federated SSO identities are bound to the individual.
3. Demo/simulation data must never be represented as real threat telemetry to external parties; the platform labels simulated output (`X-Aegis-Mode: SIMULATION`).
4. Quarantine, tracing, and blocking capabilities may only be invoked against assets/identities within the operator's authorized scope.
5. Security tooling (scanners, SBOM generators, drill scripts) must not be run against third-party systems without written authorization.
6. All use is subject to audit logging; misuse results in access revocation and, where applicable, disciplinary or legal action.
